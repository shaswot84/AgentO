# Changelog

This file documents all notable changes to this project.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added

- **Verification judge (`packages/verifier`)**: Added checks for stored proof, test links, targets, and capabilities. Require runtime proof before confirmation. Reject model claims without valid evidence IDs. Keep conflicting observations unconfirmed.
- **Verification integration and tests**: Added an optional core verification provider. Added unit tests and real demo tests over local HTTPS. Fixed demo tests return no confirmed findings. Added stored-proof replay tests and setup instructions.

- **Evidence store (`packages/evidence`)**: Added fixed evidence records with probe, capability, time, and target data. Remove secret values before storage. Added memory storage, local file storage, and proof export. Check record hashes and finding links.
- **Evidence controls and tests**: Freeze evidence when it enters the core. Stop changes to recorded facts. Reject repeated IDs and damaged files. Limit storage size. Added unit tests, adapter tests, and setup instructions. Removed a private document reference from demo instructions.

- **Security tool adapters (`plugins/tools/security-scanners`)**: Added Nuclei, ZAP, Dalfox, and sqlmap adapters. Use common result and evidence formats. Keep raw tool data private. Limit targets, requests, process time, and output size. Stop redirects and access outside the selected endpoint.
- **Scanner use and tests**: Added tool registration and policy controls. Report failed and disabled scanners in probe data. Keep scanner reports separate from verified findings. Added process tests, local HTTP tests, native tool tests, and setup instructions.

- **Execution policy (`packages/policy-engine`)**: Added checks for approved targets and tools. Check HTTP methods and redirect destinations. Limit request rates and counts. Set test risk and severity. Require approval for tests with higher risk. Use each approval once. Record decisions without private request data.
- **Runtime policy controls**: Check HTTP and browser requests before target access. Apply the same checks to login sessions and scanner requests. Stop access when a test ends. Added unit tests and local HTTP and browser tests. Added setup and use instructions.

- **Capability registry (`packages/capability-registry`)**: Added tool data for capabilities, supported CWEs, protocols, and risk. Select available adapters for plans and probes. Permit several tools to supply the same capability. Use another tool if a check fails.
- **Tool checks and tests**: Check executable files without starting them. Set time limits for adapter checks. Report missing tools with fixed error codes. Keep private paths and adapter data out of reports. Added tests for all seven CWEs, tool replacement, cancellation, and data protection. Added setup and use instructions.

- **Investigation workspace**: Added views for hypotheses and test plans. Show evidence, test steps, missing inputs, required capabilities, and rule coverage. Keep planning status separate from test results.
- **Local planning service**: Generate hypotheses and test drafts from saved application data. Save the results on the local device. Mark old results when the application data changes. Keep private plan inputs on the host.
- **Scan planning stages**: Added hypothesis generation and test planning after source analysis. Show progress and errors. The planning stages do not send requests to the target.

- **Security Test Planning (`packages/test-planner`)**: Added deterministic JSON plans for all seven supported CWEs with probe and capability requirements, ordered actions, identity and private input bindings, explicit prerequisites, and structured verification criteria. Preserves rule plan IDs and withholds blocked drafts through an optional core planner port.
- **Test Planner Verification and Documentation**: Added vulnerable and secure fixture coverage, hypothesis/rule/core compatibility checks, scope and privacy validation, package setup and usage documentation, and compiled exports. Planning remains separate from tool selection and execution.
- **Security Hypothesis Engine (`packages/hypothesis-engine`)**: Added hypothesis generation from registered CWE candidates and evidence. Added contextual rules for seven CWE types with reasons and provenance data. Added handling for fixed controls and optional schema-based model reviews. The engine keeps deterministic results if the model fails. The engine validates references to endpoints and evidence. Added limits for model usage, cancellation support, and core contract integration.
- **Hypothesis Verification and Documentation**: Added tests for evidence grounding, data privacy, invalid output handling, token budgets, and core compatibility. Added integration tests with Express and Semgrep demo applications. Added package setup instructions and usage documentation. Added dependency lockfiles, compiled exports, and a link in the root README file.
- **CWE Rules and Plugin Registry (`plugins/cwe`)**: Added seven registered rules that integrate with the core plugin lifecycle. Added application model candidates, probe plans, evidence validation, and structured verdicts. The rules use explicit cookie sensitivity and access policies. The rules handle incomplete data safely. Added CORS configuration verdicts that keep browser limits.
- **CWE Rule Verification and Documentation**: Added synthetic proof tests and negative control tests. Added compatibility tests for custom plugins and the core engine. Added tests for evidence projection and privacy. Added loopback integration tests for vulnerable and fixed targets using five probe families. Added package documentation, links, and compiled files.
- **Reusable Security Probes (`packages/runtime`)**: Added registries for typed probe capabilities. Added probes for cookies, cross-origin requests, authorization, XSS, and SQL injection. Evidence is immutable and redacted. Added persona comparisons, scanner port limits, and collection limits. Probes report observations and do not make vulnerability verdicts.
- **Probe Verification and Documentation**: Added tests for probe registration, scope limits, probe lifecycles, and cancellation. Added tests for data privacy and adapter boundaries. Added optional tests for storefront applications and Chromium. Added setup and usage documentation.
- **Application Model Frontend (`apps/frontend`)**: Added a read-only model explorer. Users can search and filter endpoints. The explorer shows authentication claims, roles, parameters, source handlers, and resources. It displays data flows, database operations, cookies, and CORS configuration. Users can inspect evidence and view run history.
- **Retained Model Integration**: Saved framework contributions, static analysis findings, and workflow identities to disk. Exposed backend model data through the local API. Added states for empty, partial, and outdated data. Added diagnostics for incompatible observations and added synthetic demo data. Added API regression tests and browser integration tests. Updated frontend documentation and built browser assets.
- **Natural-Language Browser Workflows (`apps/frontend`, `packages/workflow`)**: Connected text goals to semantic planning. The planner prioritizes recipes and keeps model configuration on the backend. Added a recipes-only mode, target personas, credential limits, and preflight checks. Saved model usage, step history, and page metadata to disk. Fixed notifications for skipped and failed tasks. Made diagnostics visible in result tabs. Added regression tests, browser tests, and setup documentation.
